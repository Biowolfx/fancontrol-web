# Plan: DSM Setup Wizard — Control Mode Selection

## Problem

Setup wizard auto-detects DSM fans and only shows a speed slider. User wants:

1. Two explicit choice buttons: "Direct Linux control (hwmon)" vs "DSM Scheme control (scemd.xml)"
2. Buttons with tooltips explaining each mode
3. Dynamic menu based on selection: hwmon → calibration flow; DSM → scheme editor (no calibration)
4. If hwmon unavailable — only DSM button active, hwmon greyed out with explanation
5. Remove "Not calibrated" badge for DSM fans (meaningless)
6. Fix fan label "DSM Fan (Synology-RX424)" — clean name
7. Add notification that DSM control only works via scheme editing, not direct speed control

## Files to modify

- `templates/index.html` — wizard HTML (lines 286-316)
- `templates/js/main.js` — `renderDiscoveredHardware()` (line 3236+)

## Changes

### 1. `index.html` — Replace wizard action section

Replace the action div (lines 290-315) with:

```
setup-step-action (hidden by default):
  ├── control-mode-select: Two mode selection buttons
  │   ├── btn-hwmon: "Direct Control (hwmon)" — tooltip: "Direct PWM control via Linux sysfs. Requires calibration."
  │   └── btn-dsm: "DSM Scheme Control" — tooltip: "Control fans by editing DSM scemd.xml schemes. No calibration needed."
  ├── hwmon-action (hidden): calibration hint + calibrate button
  ├── dsm-action (hidden): DSM warning text + scheme editor shortcut
  └── calibrate-loader (existing)
```

Remove: `dsm-speed-section` (the slider + Apply button), `skip-calibrate-btn`

### 2. `main.js` — `renderDiscoveredHardware()`

Replace the bottom section (lines 3308-3335) that auto-selects mode with:

- Always show `control-mode-select`
- If `has_hwmon_pwm` → hwmon button active; else → greyed out + "hwmon not available on this system"
- If `has_scemd` → dsm button active; else → greyed out
- On hwmon button click: show `hwmon-action` (calibration)
- On DSM button click: show `dsm-action` (warning + "Open DSM Scheme Editor" button)

### 3. `main.js` — Fan label cleanup

In `renderDiscoveredHardware()` fan section (line 3269), strip the "(Synology-xxx)" suffix from DSM fan labels:
```js
const cleanLabel = fan.label.replace(/\s*\(Synology-[^)]+\)/, '');
```

### 4. `main.js` — Remove "Not calibrated" for DSM fans

Line 3272: only show "Not calibrated" badge when `fan.control_method !== 'dsm_scemd'`:
```js
if (fan.control_method !== 'dsm_scemd') {
  html += `<span class="...">Not calibrated</span>`;
}
```

### 5. DSM warning text

When DSM button is clicked, show:
> "DSM mode controls fans by editing system scheme files (scemd.xml). Direct speed control is not available — you configure temperature thresholds and corresponding fan speeds in the scheme editor."

Button: "Open Scheme Editor" → calls `showView('dsm-scheme')` + `wizardStep = 'done'` + `showMainScreen()`

## Verification

1. On Synology with official kernel (no hwmon): wizard shows DSM button active, hwmon greyed out. Click DSM → warning text + scheme editor button. No calibration.
2. On custom kernel (hwmon available): both buttons active. Click hwmon → calibration flow. Click DSM → DSM flow.
3. Fan names clean, no "Not calibrated" for DSM fans.
4. `git push` with version bump.
