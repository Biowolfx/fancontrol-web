# Plan: Fan Health Monitoring — Slowdown/Stop Detection + Visual Alerts + Service Tracking

## Overview

Add hardware health monitoring for fans: detect slowdown (bearing wear) and complete stop, show yellow/red visual indicators in dashboard cards and sidebar, track fan replacement/service dates, and offer calibration after service.

---

## Part 1: Backend — Fan Health Detection

### 1.1 New fields in fan state dict

**File:** `core/hardware.py` (in `discover_fans_and_sensors()`)

Add to each fan dict:
```python
'health': {
    'status': 'healthy',       # 'healthy' | 'slowing' | 'stopped' | 'needs_calibration'
    'rpm_baseline': 0,         # rolling average RPM at current PWM (learned over ~5 min)
    'slowdown_since': None,    # timestamp when slowdown first detected
    'stopped_since': None,     # timestamp when RPM=0 first detected
    'last_service_date': None, # ISO date string of last replacement/service
    'calibration_required': False,  # True after service until calibration done
}
```

### 1.2 Health detection algorithm

**File:** `core/control.py` — new function `check_fan_health()` called from `loop()` after `refresh()`

Algorithm:
```
For each fan with writable=True and mode != 'off':
  rpm = fan['rpm']
  pwm = fan.get('current_pct', 0) or fan.get('manual_pct', 50)
  cal = fan.get('calibration', {})
  max_rpm = cal.get('max_rpm', 0)
  
  # --- STOP DETECTION ---
  # RPM < 10 at PWM > 20% for 2 cycles (10s) = stopped
  if rpm < 10 and pwm > 20:
      if fan['health']['stopped_since'] is None:
          fan['health']['stopped_since'] = now
      if now - stopped_since >= 10s (2 cycles):
          fan['health']['status'] = 'stopped'
  else:
      fan['health']['stopped_since'] = None
      if fan['health']['status'] == 'stopped':
          fan['health']['status'] = 'healthy'  # recovered
  
  # --- SLOWDOWN DETECTION (COMBINED) ---
  if rpm > 0 and pwm > 0:
      # Calculate expected RPM based on available data
      if max_rpm > 0:
          # Use calibration data: expected = max_rpm * (pwm/100)
          expected_rpm = max_rpm * (pwm / 100)
      else:
          # No calibration: use rolling EMA baseline (alpha=0.1)
          if fan['health']['status'] in ('healthy', 'slowing'):
              if fan['health']['rpm_baseline'] == 0:
                  fan['health']['rpm_baseline'] = rpm
              else:
                  fan['health']['rpm_baseline'] = 0.9 * fan['health']['rpm_baseline'] + 0.1 * rpm
          expected_rpm = fan['health']['rpm_baseline']
      
      if expected_rpm > 0 and rpm < expected_rpm * 0.5:  # >50% drop
          if fan['health']['slowing_since'] is None:
              fan['health']['slowing_since'] = now
          if now - slowing_since >= 15s (3 cycles):
              fan['health']['status'] = 'slowing'
      else:
          fan['health']['slowing_since'] = None
          if fan['health']['status'] == 'slowing':
              fan['health']['status'] = 'healthy'  # recovered
  
  # --- NEEDS CALIBRATION ---
  if fan['health'].get('calibration_required') and fan['health']['status'] != 'stopped':
      fan['health']['status'] = 'needs_calibration'
```

### 1.5 Service API endpoint

**File:** `server/routes.py` — new endpoint

```python
@routes.route('/api/fan/<fan_id>/service', methods=['POST'])
def api_fan_service(fan_id):
    """Record fan replacement or service event."""
    data = request.get_json(force=True)
    action = data.get('action', 'service')  # 'service' or 'replace'
    date = data.get('date', datetime.now().isoformat())
    
    fan = state.get('fans', {}).get(fan_id)
    if not fan:
        return jsonify({'error': 'Fan not found'}), 404
    
    fan['health']['last_service_date'] = date
    fan['health']['calibration_required'] = True
    fan['health']['status'] = 'needs_calibration'
    fan['health']['rpm_baseline'] = 0  # reset baseline
    fan['health']['slowdown_since'] = None
    fan['health']['stopped_since'] = None
    
    save_config()
    return jsonify({'status': 'ok', 'health': fan['health']})
```

## Part 2: Backend — Alert Emission

### 2.1 Emit health alerts from control loop

**File:** `core/control.py` — in `check_fan_health()` or after it

After detecting a status change, emit SocketIO events (reuse existing `check_alerts` infrastructure):

```python
# On status transition
if old_status != new_status:
    if new_status == 'stopped':
        socketio.emit('fan:health', {
            'fan_id': fan_id, 'node_id': 'local',
            'status': 'stopped',
            'label': fan['label'],
            'message': f'Вентилятор {fan["label"]} остановлен!',
        })
    elif new_status == 'slowing':
        socketio.emit('fan:health', {
            'fan_id': fan_id, 'node_id': 'local',
            'status': 'slowing',
            'label': fan['label'],
            'message': f'Вентилятор {fan["label"]} замедляется (износ подшипника)',
        })
    elif new_status == 'needs_calibration':
        socketio.emit('fan:health', {
            'fan_id': fan_id, 'node_id': 'local',
            'status': 'needs_calibration',
            'label': fan['label'],
            'message': f'Вентилятор {fan["label"]} требует калибровки',
        })
    elif new_status == 'healthy' and old_status in ('stopped', 'slowing', 'needs_calibration'):
        socketio.emit('fan:health:cleared', {
            'fan_id': fan_id, 'node_id': 'local',
        })
```

## Part 4: Frontend — Service/Replace UI

### 4.1 Service button in fan inspector

**File:** `templates/js/main.js` — in `updateInspector()` (line ~2854)

Add a service section after the calibration section:
```javascript
// Health & Service section
const health = fan.health || {};
const serviceSection = document.getElementById('fan-service-section');
if (serviceSection) {
    const lastService = health.last_service_date;
    const needsCal = health.calibration_required;
    const status = health.status;
    
    let html = '';
    if (lastService) {
        html += `<div class="text-xs text-gray-500">${t('fan.service_date')}: ${new Date(lastService).toLocaleDateString()}</div>`;
    }
    if (status === 'stopped' || status === 'slowing' || needsCal) {
        html += `<button onclick="showServiceFanModal('${fanId}')" class="mt-2 px-3 py-1.5 bg-yellow-900/30 border border-yellow-700/50 rounded text-xs text-yellow-400 hover:bg-yellow-800/50 transition">
            ${t('fan.service')} / ${t('fan.replace')}
        </button>`;
    }
    if (needsCal) {
        html += `<div class="mt-2 px-2 py-1 rounded bg-yellow-900/20 border border-yellow-700/30 text-xs text-yellow-400">
            ⚠ ${t('fan.calibration_required')}
            <button onclick="startFanCalibration('${fanId}')" class="ml-2 underline hover:text-yellow-300">${t('inspector.calibrate', 'Calibrate')}</button>
        </div>`;
    }
    serviceSection.innerHTML = html;
}
```
